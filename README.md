# Predictive Process Monitoring of Temporal Logic Specifications with Statistical Guarantees

You need to download the BPIC Challenge 2017 dataset and save it into a folder named dataset. 

In the repository there is another folder, named mitl, with all the code for monitoring of Boolean semantics and time-robustness of MITL formula interpretated over finite time sequences. 

The rest of respository is composed of 4 numered jupyter notebook. You can execute them in orders.

Please refers to requirements.txt for list of Python dependencies.
